# РЗДС — приложение для телефона

Устанавливаемое веб-приложение (PWA) к «Плану производства РЗДС»: план по станкам,
задачи себе и поручения другим, ответы со смены, push-уведомления.
Магазины приложений не нужны: открыть адрес в Safari → «Поделиться» → «На экран „Домой“».

- `index.html`, `app.css`, `js/` — само приложение, без сборки.
- `config.js` — адрес сервера (веб-приложение Apps Script). Пусто — демо-данные.
- `sw.js` — работа без связи и приём push-уведомлений.
- `tests/smoke.cjs` — прогон всех экранов на демо-данных.
