Дополнение к основному КОНТЕКСТ.md проекта планировщика. Здесь — только то, что касается приложения на телефон.

## Что обсудили и решили
- Путь: веб-приложение, устанавливаемое на экран телефона (PWA). Нет App Store / Google Play, нет ежегодных 99 $ и зарубежной карты.
- Данные остаются в Google-таблице, план работает как сейчас.
- Уведомления: основной канал — push самого приложения (не зависит от Телеграма, который в РФ работает с перебоями). Бот @rzds_prod_bot остаётся запасным каналом.
- На iPhone push работает только после «Добавить на экран Домой», iOS 16.4+. Каждому работнику показать один раз.
- Для push нужен маленький сервер (бесплатный тариф облака или несколько сотен ₽/мес) — единственная возможная трата.
- Порядок работы: сначала кликабельные макеты → согласование → код.

### Решения
| Решение | Почему |
|---|---|
| Резервную копию не пересылать — взял сам с компьютера через подключение к нему | «ПП резервная копия» на рабочем столе и архив от 13.09 в «Загрузках». Это версия 26; живой код новее (доступ по Google-аккаунту, бот на отдельном адресе и т.д.) — его возьму из проекта Apps Script |
| Хостинг приложения — GitHub Pages (бесплатно) | Cloudflare в России душат с 2025 года; GitHub открывается. Выкладываю я сам после подключения GitHub к Claude |
| Push-уведомления шлёт сам Apps Script, без отдельного сервера | Сделано: подпись VAPID (ECDSA P-256) и шифрование RFC 8291 (ECDH + HKDF + AES-128-GCM) на чистом JS. Проверено в Node против node:crypto — совпадает. Итог: 0 ₽, никаких продлений (меняет прежний пункт про «маленький сервер») |
| Вход в приложение — одноразовый код из плана, а не Google-вход | Google-вход внутри приложения, установленного на экран «Домой» айфона, работает ненадёжно. Код вводится один раз на телефоне, каждый вход можно отозвать |
| Важность задач — четыре ступени, как в планировщике: срочно / важно / обычная / потом | В макете было три; данные уже живут в четырёх |
| Демо-режим, пока сервер не подключён | Можно открыть и потрогать всё приложение, в настоящий план ничего не попадает |

### Что выяснилось и что решено
| Решение | Почему |
|---|---|
| Код годится на 3 входа за сутки, у каждого телефона своя строка | У Safari и иконки «Домой» разная память — вход в Safari иконке не передаётся, а код сгорал с первого раза |
| Кнопка «Я владелец — получить код» на экране входа → страница плана …/exec?appcode=1 (вход через Google) показывает код | В приложении Google Таблиц на айфоне своих меню нет — пункт «Вход в приложение на телефон» с телефона недоступен |
| Кнопка, идущая к серверу, сразу крутилка и не нажимается повторно; «Поставить» уводит в список мгновенно, «сохраняю…» → «✓» | Иначе кажется, что ничего не произошло, и второе нажатие = вторая задача |
| Календарь срока виден сразу: 5 недель от текущей, время кнопками | Системное поле даты iOS пустым выглядит белой полоской; месячная сетка 29-го числа почти вся серая |
| План на сервере считается один раз на версию и лежит в кэше (5 мин) | Журнал выполнения за 28.09: каждый запрос приложения 4–13 с — сервер на каждое нажатие читал 8 листов и пересчитывал план. Стало 3–4,5 с |

### Ревю 360 и анализ — документ «РЗДС — ревю 360 приложения и анализ похожих»
Главное: 6 из 11 переключателей уведомлений не подключены на сервере (утренняя сводка, недельный отчёт, «за час до срока», повтор непрочитанного, «отчитаться по смене», дубль в Телеграм; «тихие часы» на экране вкл, на сервере выкл).
